# Acuerdos de Trabajo (Working Agreements)

- **Commits:** Se debe utilizar Conventional Commits (ej. `feat: agregar login`, `fix: corregir overflow en modal`).
- **Ramas (Branches):** Usar el formato `tipo/nombre-tarea`. Ej: `feat/login-screen`, `bugfix/token-refresh`.
- **Merge a Main:** Ningún desarrollador puede hacer push directo a la rama `main`. Todo código debe llegar a través de un Pull Request revisado por al menos un compañero.
- **Sincronización:** Cada día a las 9:00 AM se hará un Daily Standup de 15 minutos en Discord/Teams para comentar qué se hizo ayer, qué se hará hoy y si hay bloqueos.
