# Glosario

Diccionario de términos técnicos y de negocio utilizados en HabitApp para mantener un lenguaje ubicuo entre el equipo.

- **MVP:** Minimum Viable Product. La primera versión lanzable de la app.
- **JWT (JSON Web Token):** Token de seguridad generado por NestJS usado para autenticar al usuario móvil.
- **Riverpod:** Gestor de estado usado en la app móvil.
- **Dio:** Librería de peticiones HTTP en Dart, usada para comunicarse con NestJS.
- **Supabase:** Plataforma Backend-as-a-Service usada en este proyecto puramente como base de datos PostgreSQL.
- **FCM (Firebase Cloud Messaging):** Servicio usado para enviar notificaciones Push a los teléfonos.
- **GoRouter:** Paquete de Flutter usado para manejar la navegación interna entre pantallas.
